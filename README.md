# ML101-Code-Examples
Reference the spreadsheet: https://docs.google.com/spreadsheets/d/1hwD1Ae2oNvvPGOWaTWgYH5ei9bDLqz9bijWz1FwF_4k/edit?usp=sharing

When adding code example follow these rules:
1. Create your own branch named after your name: `[NAME]_wk[WEEK_NUMBER]`
2. Make a folder titled by the topic name: `[f | w]_week_[WEEK_NUMBER]_[TOPIC_NAME]`
3. Add your code examples into that folder. There should be three types of notebooks: branching, fill-in-the-blanks, and master.
4. Make a PR and merge it with the main branch after another person reviews the code.
5. When presenting make sure that upload the notebook to Google Colab and send it in `#workshops` in the discord.
